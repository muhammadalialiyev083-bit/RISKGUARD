# Legacy FastAPI reference

Bu katalog tarixiy prototip sifatida saqlangan. UzHi production backend `../backend/` dagi Django/DRF ilovasidir.

- Bu katalogni productionga deploy qilmang.
- Yangi endpoint, migratsiya yoki xavfsizlik tuzatishlarini bu yerga qo‘shmang.
- Olib tashlashdan oldin tarixiy test va domain solishtirish zarurati yo‘qligini alohida tasdiqlang; mavjud ma’lumot yoki deployni avtomatik o‘chirmang.
