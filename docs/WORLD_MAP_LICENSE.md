# World map data attribution

Map data is bundled from world-atlas 2.0.2 (`countries-110m.json`), based on Natural Earth 1:110m country boundaries. Natural Earth data is public domain. Boundaries are generalized geographic context, not a legal boundary definition or a street-navigation map.

Sources: https://github.com/topojson/world-atlas and https://www.naturalearthdata.com/about/terms-of-use/
